## 量化门槛

- A0源文筛选：报告逐例修复/损失、FLEURS/普通声WER、自然耳语严格正确与非空覆盖、音乐非空原输出。至少目标源文错误净减20%且净修复≥3；弱声严格正确/覆盖不降、关键数字否定不新增错误。音乐非空原文全部保留，不用括号/标签删除刷通过。类别护栏失败则否决该固定ASR候选，保留定位工作，不直接接翻译上线。
- A1/A2最终内容：完整语义正确率至少+5个百分点，或目标错误净减≥20%且净修复≥3；全体正确/覆盖不降、新增关键错误0。语义项分母、整句分母、英语WER分开，来源少不能把点估计当证明。
- 端到端：人工语义结束→本机实际绘制稳定中文，P50目标改善≥20%、绝对P50≤3秒/P95≤6秒，P95回退≤5%。有效输出少于60或没有真实绘制只报中位/代理；漏字幕单独计失败。
- 单模型驻留阶段试验不等于实时级联：ASR卸载、翻译模型加载及切换开销必须计入后续真实路径，不能用离线分批的两段中位数相加冒充端到端延迟。若这项成本超标，路线不通过速度关口。
- 术语/场景继续原目标：术语至少净修复3例且错误减少20%；地图/队伍精确率各95%，充分证据后30秒确认覆盖80%，冲突≤2完成片段解除。ASR改善只意味着更可能具备实体，不能代替这些验收。
