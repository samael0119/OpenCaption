# 第5完整轮结论：混合识别的源文收益尚未转成可靠中文收益

2026-10-15。本轮完成机制定位、两个有界路由候选、30次实际文本翻译、普通声/自然耳语/低幅/音乐正反例回放及量化审计。按本轮计划结束后暂停opencaption，不启动第6轮。停止不是因为周额度不足：最近周额度剩余91%，未触发用户40%额度止损线。

## 数字与结论

|指标|原E2B缓存基线|候选1：仅空输出回退|候选2：短文本也回退|
|---|---:|---:|---:|
|源文整句严格正确（36语音）|13/36|19/36|17/36|

|低幅语音非空覆盖|6/6|6/6|6/6|

上述是41条已知材料的缓存组合回放，0次新ASR/基线推理，不是独立确认。候选1新增30次文本翻译（3批各10），30/30非空不代表30条正确。源文改善具有开发证据，尚不能视作中文准确率提高。

候选1有三例原本识别正确的耳语继续被错误翻译：desk→BUT DESK→“但是桌子”、run→RUM→“朗姆酒”、browser→BROW SIR→“眉先生”。这证实非空不等于可靠。另有brother→“哥哥”的未给定年龄细化、Shaggy→“毛毛”的姓名保持问题，见逐例原输出。候选1不适合直接替换产品默认路径。

候选2仅作一次有依据修订：ASR识别文本超过6个空格分词才用ASR，否则回退原E2B。没有根据金标/真实类别选择答案；阈值是在观察错误后提出，属于开发调参，不能当保留集证据。不做阈值扫描/第三候选，不增加模型请求，所有相同文本翻译明确复用候选1缓存。

在固定英文参考的12普通句AI辅助完整中文核查中，候选2为5/12→6/12；其余24语音回退原输出不变，因此36条语音净修复1句（+2.78个百分点），低于整体+5个百分点或至少3例净修复的继续门槛。此核查不是独立人工金标；疑义算未通过，逐项理由/原文/SHA保留，未重评旧FLEURS评分。不能据此宣称真实中文准确率是该比例。候选2源文净修复4句与完整中文净修复1句属于不同指标。

例如“new king replied”的归属得到修正，但同一句仍出现原文没有的“喝”，所以记录局部修复，未计完整句正确；“fled in disgrace”和文学对话中的returned/inquired仍无法仅靠更正确源文自动解决。这轮的主要瓶颈已从低幅漏识别转为识别可靠性选择与文本翻译忠实性。
