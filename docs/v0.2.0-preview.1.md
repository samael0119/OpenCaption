## 本机复现

JDK17：~/Tools/java/eclipse-temurin-jdk17；使用scripts/flutterw。

```sh
OPENCAPTION_JAVA_HOME="$HOME/Tools/java/eclipse-temurin-jdk17" \
OPENCAPTION_CMAKE_JOBS=1 \
scripts/flutterw build apk --debug --flavor gemmaE2E --target-platform android-arm64 --no-pub
```
