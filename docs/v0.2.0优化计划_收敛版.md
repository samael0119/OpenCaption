## 1. 决策原则

目标是证明用户能看到更快、更准的字幕。单测数量、词条数量、运行小时数不作为优化收益。先定位损失发生在哪一层，再选一个变量改进；内容质量有收益后再做完整稳定性验收。

保留当前停顿分段、有界队列、词库治理及UI；768上下文和当前模型作为冻结基线。暂停追加UI美化、扩大词库、语义前文及一跳关联上线。选库默认启用现有自动辅助的行为保留；不得靠关闭辅助、漏掉难例或放宽评分变成通过。

## 3. 先建立一份可决策的数据集（G0）

先盘点现有材料，只补不足项。以下是最低筛选规模，不代表足以精确估计所有上线指标。

- 连续赛事：至少6段、来自至少3场不同比赛，总计至少20分钟；保留时间顺序，覆盖至少2张地图、队伍/选手、切图、历史或转会叙述。若真实材料缺历史/转会，另列有来源的文本机制用例，不能冒充真实音频覆盖。
- 质量评分：至少100个完整语义单元，其中至少40次术语/名称出现、20次数字/否定；自然弱声至少20条、至少3位说话人。不得把合成衰减计作自然弱声。
- 独立非语音：至少20段非零音乐/环境声、至少5个来源，总长至少10分钟；另保留所有已知失败作回归。
- 按完整比赛/说话人/来源划分开发与保留集，约各半；同一来源不得拆到两侧。上面的质量事件数量以保留集计。保留集至少有30个预先标注的停顿语义结束点，全部有效输出至少60个才报告P95；不够则只报分布和样本数。
- 冻结音频哈希、来源许可、原文、中文语义要点、语义结束点、场景充分证据点及评分规则。参考在看到候选输出之前确定；模型转录不能作金标。AI辅助参考/评级明确标识，未经独立人工核验只能作探索性结论。

资料收集最多2个工作包：本机清点1包，公开合法来源补齐1包。仍缺材料则列明缺项、继续有限机制定位与候选修复；不无限搜索，不用旧调参样本替换保留集。如需要人工复核，交付具体片段和待判定项，避免要求用户从头标注整套材料。

现有6句FLEURS可以作一次通用翻译诊断，不能替代赛事集。取消“必须先完成3份长稳才能做质量小实验”的实验顺序依赖；恢复执行时须显式更新旧入口保护，保留单模型互斥、内存限制及暂停保护。

## 4. 统一计分方式

- 中文语义正确率：完整保留必要事实且无矛盾的单元数/全部参考单元数。漏字幕、无法判定均不算正确，单独报告；允许等价表达。另报告语义覆盖率，防止仅输出容易句子抬高正确率。
- 术语/名称：按预先标注的出现次数计算正确率，别名等价规则预先冻结。报告修复数、新增错误数及净减少率 `(基线错误数－候选错误数)/基线错误数`。基线为0时不计算百分比。
- 关键错误：逐项报告数字、否定、人物/队伍归属颠倒的错误数量和分母；新引入关键错误必须为0。
- 音乐：同时报告出现虚构的片段数/总片段数、虚构次数/音频分钟，不能把循环窗口当独立来源。
- 稳定中文延迟：人工语义结束时刻→本机真实绘制出正确且不再修订的中文时刻。绑定音频时间轴、单调时钟和绘制证据；只收到widget事件属于代理。固定窗和停顿策略使用同一素材、模型、提示及负载，交换运行顺序。漏句不填0延迟，单列失败并受覆盖门槛约束。
- 对配对质量给出增益/损失明细，并按完整来源做配对重采样区间；来源少时明确区间不可靠。置信区间跨0只能称“未证实”，不能只凭点估计达标。

## 6. 强制停止与转向规则

**一个方向最多2个候选修订，加1次独立确认；不是每个参数各给2次。** 提示措辞、同一VAD阈值、上下文长度的微调属于同一方向，共享额度。历史失败计入记录：低VAD音乐拒绝已严重损害耳语，冻结；单纯放大模型和重复同一ASR诊断，没有新证据不重开。

1. 每次实验前填写：假设、唯一主要变量、固定数据、主指标、护栏、最大请求数和失败后动作。执行时不临时追加样本或重试模型答案。
2. 候选1无收益，只有错误分析提出新的可检验机制解释，才允许候选2；否则立即停。
3. 连续2个候选未达到继续门槛，或独立确认未复现，标为“停止/收益未证实”。保留日志、失败案例和原因，禁止继续换提示碰运气。
4. 出现新增关键错误、弱声覆盖下降或资源越界，立即否决该候选。可修确定的程序bug，但不能无上限修补并重复消耗同一保留集。
5. 保留集只对选中的候选做一次确认；查看结果后即变为已观察材料。后续若要重新确认，需新的来源，且不得绕过方向次数上限。
6. 只有新独立证据、明确实现缺陷或实质不同机制才可提议重开；先写出为何能改变之前结论，由用户决定新一轮投入。

零失败只是这份有限测试集上的结果，不是现实零风险证明。正式门槛未达到时，可以提出缩减版本范围或更换路线，但不能自行降标。
