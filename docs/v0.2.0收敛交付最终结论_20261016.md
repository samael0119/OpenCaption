## 仍缺哪些验收

1. **主要停顿收益未通过。** 开发代理仅8.05%，既定门槛10%且200ms不降低；更严格的“预标注停顿结束→稳定正确完整中文显示”仍未验收。停止本方向，未跑额外确认，不扫描第三阈值/相位。
2. **没有本轮中文准确率改善证据。** 没有新增独立人工金标；54/54格式或可见帧不能换算中文正确率。全部raw保留，未重评旧同case/raw/ref制造收益。新生成仍可见专名/句意缺陷，不编造正确分数。
3. **独立参考仍缺。** 一次限定清点20登记文件，合格新确认0；目标仍为≥3来源6–8分钟、≥30停顿/60语义单元。原29条SRT来自ASR时间戳和辅助校对，资格已明确更正；跨30秒边界7/15/21保留，不填0延迟或删难例。逐句实际输出复核包已交付，但它仍是旧开发材料。
4. **P95/弱声/音乐等最终护栏未验收。** 有效独立观测不足60，不报告正式P95；本包不是弱声/非零音乐集。旧音乐误报仍披露，未以关闭高级功能或全弃权刷通过。默认词库实验辅助和既有地图/冲突机制保留，不宣称真实场景95%精确率。
5. **最终包D未触发。** 本轮没有做最终Android构建/签名或补齐3×60分钟联合长稳。旧联合run1依赖适用性仍需审定，人工中止run2不能续接凑数。原版完整90%/95%目标延期，仍未通过；新版预览也不能称通过。
