# CS 采访实时字幕（OpenCaption）

产品需求文档 PRD · 小米 15 优先

版本  v1.0 · 修订 2   |   日期  2026-09-07   |   状态  开发评审草案

目标用户  中文 CS 观众   |   首发  Android   |   后续验证  iPhone 12

## 产品定义

定位成  **“通用实时字幕翻译工具＋可安装的领域语言包”** 。CS 是第一个语言包，之后可以扩展到其他电竞、体育赛事，甚至技术会议。

场景：用户在电脑或电视上观看 CS 赛前、赛后英文采访，将手机放在外放音源附近，打开 App 即可持续阅读简体中文字幕。源设备无需安装软件，也无需与手机配对。

> 核心价值：听懂选手与主持人表达的关键信息，正确处理口音、CS 术语和选手 ID，并让字幕在整个采访过程中保持可读。

### 修订 2 · 技术评审决定（2026-09-07）

- 一个 App 独立完成收音、识别、翻译；Flutter＋Kotlin＋whisper.cpp／llama.cpp，不开发独立后端，首版不引入 Rust。
- 本地优先，允许首次下载模型；默认离线组合必须通过原质量、延迟和稳定性门槛。未通过则继续验证，不以联网版替代发布。
- 首批候选：small.en Q5_1＋ML Kit、small.en Q5_1＋Qwen2.5-0.5B Q4_K_M／Qwen3.5-0.8B Q4_0；NLLB-200 distilled 600M 待推理引擎支持后加入实测。base.en Q5_1 用于识别对照。候选不等于通过验收。
- 外部增强只包含用户主动配置的文本翻译；手机直连 Chat Completions 兼容接口，配置地址、模型名和可选 API Key。不上传音频、不自动切换服务。
- 整进程峰值内存 1.5 GB 为初始优化目标，可基于实测评审调整；准确率和延迟门槛不随之降低。
- 开发阶段、任务依赖和验收详见 [开发计划](开发计划.md)。

### 已确认与设计假设

- 已确认：英语转中文；主要内容为 CS 赛前、赛后采访；通过手机麦克风听外部设备；小米 15 优先，另有 iPhone 12 可测试。
- 设计假设：首版为个人自用／小规模测试；允许可选云端服务；默认简体中文；正常使用时应用位于前台、屏幕常亮。

## 范围、用户任务与设备

### 用户任务

采访开始后快速开启字幕；在下一段回答到来前读懂上一句；遇到选手名或术语时能对照英文；短暂断网后知道哪里漏听；采访结束即可停止收音。

| 优先级           | 范围                                                                                                                    |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------- |
| P0 · 首版必须   | 麦克风授权与音量反馈；开始／暂停／结束；英中字幕；CS 术语与当场名称；本地识别与离线翻译；必要模型管理；可选外部文本翻译；中断与错误提示；会话内回看；诊断指标 |
| P1 · 验证后加入 | 扩展领域语言包管理；会话文本保存与导出；iPhone 12 适配                                          |
| P2 · 后续探索   | 斗鱼同机直播翻译＋悬浮字幕（暂缓验证）；自动名称库更新；自定义词表；更多语言；直接接收电脑音频                          |
| 首版不交付       | 中文配音、跨应用悬浮窗、系统音频抓取、后台／锁屏持续收音、说话人身份识别、账号付费体系、整场解说优化                    |

### 使用边界

- 建议手机靠近音箱、麦克风无遮挡。初始参考距离 0.3～1 米，按真实收音结果调整；这不是可保证的有效距离。
- 手机不区分“电脑声音”和旁人说话。多个声音重叠时允许漏译或标记未听清，不根据赛况编造答案。
- 首版不对直播进行延迟播放，中文字幕自然落后原声；用户通过历史字幕补看。

首页：开始字幕为唯一主按钮；当场信息可跳过；显示当前模式。字幕页：中文为主、英文为辅；固定底部控制区；用文字配合颜色表达状态。设置页：字号、英文显示、主题、服务连接与语言包。

## P0 功能与会话状态

### F01 · 启动、授权与收音

用户点击开始后请求麦克风权限；首次启用外部翻译时说明仅文字及相关上下文会发送到用户配置的服务。拒绝权限时停留首页，提供“去设置”入口，不循环弹窗。完成授权后检查本地模型完整性并加载；仅外部翻译模式检查服务可用性，再进入收音。

展示音量活动指示，不能将“有音量”标成“听懂了”。连续 8 秒未检测到人声时显示“未检测到讲话，可将手机靠近音箱”；不中断会话。暂停与结束均须在 1 秒内停止采集和提交新音频。

### F02 · 识别与字幕提交

固定英语。按讲话停顿分段，同时限制长句等待；分段参数在技术验证中调优。识别器支持时显示临时英文；中文默认在稳定短句后提交。若只支持分块返回，不伪装逐字流式结果。

每句有稳定 ID。临时结果在原句位置替换；确认结果追加一次；重试与乱序返回不得重复、倒序或覆盖已确认字幕。超过 10 秒仍无译文时，该句显示“翻译超时”，保留英文并继续后续句。

### F03 · 暂停、回看与结束

暂停时冻结收音、保留字幕；已提交请求可在 3 秒内完成，超时取消。恢复时从当前声音继续，并标记暂停间隔。结束时停止新输入，最多等待 3 秒收尾，取消剩余请求，进入本次字幕回看。

| 状态           | 进入条件                 | 用户可见行为                   |
| -------------- | ------------------------ | ------------------------------ |
| 就绪／准备中   | 首页；授权、模型准备或可选服务检查     | 开始按钮／准备提示；可取消     |
| 收音中         | 采集成功                 | 音量活动、持续字幕、暂停／结束 |
| 等待讲话       | 8 秒无人声               | 提示靠近音源；继续监听         |
| 已暂停         | 用户暂停或应用离开前台   | 显示暂停；返回后手动继续       |
| 恢复连接       | 外部文本翻译网络或服务短暂失败       | 保留英文与已有字幕；仅外部翻译恢复连接         |
| 已结束／不可用 | 用户结束；授权或服务失败 | 回看；显示可执行的修复入口     |

切后台、锁屏、来电或其他录音抢占时，首版暂停收音；回来后明确提示继续。录音期间仅维持屏幕常亮，不要求用户修改系统全局省电设置。

## CS 术语与翻译质量规则

### F04 · 当场信息与词表

预置精简 CS 术语表；用户可在开始前填入战队、选手 ID 和地图。首版不依赖自动抓取赛事名单。会话仅注入相关词条，避免把所有选手名塞入每次请求。名称提示只提高识别倾向，不保证结果正确。

| 表达                  | 默认含义／输出       | 边界                           |
| --------------------- | -------------------- | ------------------------------ |
| trade / trade kill    | 补枪／补枪击杀       | 涉及人员交易时按原意           |
| eco round / force buy | 经济局／强起         | 不要按一般财经词义翻译         |
| save                  | 保枪                 | save money 译为省钱            |
| utility               | 道具                 | 结合具体烟、闪、火的上下文     |
| execute               | 战术进攻／爆弹进攻   | 按整句决定，不强制逐词替换     |
| rotation / retake     | 转点或回防／回防夺点 | 区分时间点与攻守语境           |
| clutch / opening duel | 残局／开局对枪       | 不擅自添加“一打几”           |
| 选手 ID、战队、地图   | 优先保留标准原文     | 未知名称保留识别文本并允许回看 |

### F05 · 翻译约束

- Qwen 与外部文本翻译提供最近最多 3 句已确认英文，初始上限约 160 个英文词；每句最多注入 6 个命中语料词条。Qwen 初始窗口 4096 tokens，超限先移除最旧历史，只输出当前句译文。暂停即清空上下文；连续中断超过 30 秒或更换采访也清空。ML Kit 按稳定短句调用，不宣称支持提示词、术语注入或历史上下文。
- 保留否定、可能性、因果、比分和数字。不得补写比赛结局、选手身份、发言对象或未提及的战术。
- 识别文本、历史文本均作为待翻译内容，不执行其中的指令；译文不得输出分析过程、问候或额外解释。
- 不要向用户显示模型自报的“准确率”。无可靠结果时用“未听清／暂未译出”，保留可用原文。

### 词条数据与验收样例

语料使用 manifest 加载多个版本化领域包；同一领域允许拆成多份文件，加载时按规范化英文主词合并去重。词条字段包含 ID、英文表达、别名、中文建议、备选译法、类别、优先级、适用语境、避免直译、保留原文标志和来源引用。每句只选择命中主词或别名的少量高优先级词条进入翻译上下文；最高优先级英文词条以固定长度上限加入本地识别提示。当场信息优先加入识别提示且仅本次会话有效。内置语料随 App 版本更新，发布前必须核验每份语料包的来源与再分发许可状态。

构造样例：We needed to trade better, but we decided to save in the next round.
期望：我们需要把补枪做得更好，但下一回合我们决定保枪。
负例：I wanted to save money. 必须译为“我想省钱”，不能误译为保枪。

## 技术路线与模型选型门槛

默认本地链路；通过同一开发集比较候选，并用独立保留集验收。不把具体模型名称写死在用户主界面。正式版只开放通过验收的组合，候选仅在开发评测入口提供。

| 模式 | 处理链路 | 发布策略 |
| --- | --- | --- |
| 离线字幕 | 手机收音 → 本地英语识别 → 本地英中翻译 | P0；首发必须通过全部质量与稳定性门槛 |
| 外部文本增强 | 手机收音 → 本地英语识别 → 用户配置的外部文本翻译 | P0 可选；不替代离线验收，不自动开启 |

### 固定候选与实现边界

识别：whisper.cpp small.en Q5_1（文件约 190 MB）；base.en Q5_1（文件约 60 MB）作速度、功耗与准确率对照。

翻译：ML Kit 作轻量候选；Qwen2.5-0.5B Q4_K_M 与 Qwen3.5-0.8B Q4_0 由 llama.cpp 加载，Qwen3.5 关闭思考模式。先用人工参考英文比较翻译，再接入识别结果，最后以小米外放实录评测整个链路。NLLB-200 distilled 600M 需等待 llama.cpp encoder-decoder 支持或接入独立运行时。

ML Kit 是 Google 端侧 SDK，并非可自主分发模型的开源引擎。语言模型由 SDK 下载管理；翻译输入和输出在设备处理，但 SDK 可获取更新及发送性能／使用指标。不能将其描述为绝不联网，也不能预设 CS 质量达标 [S5、S6、S14]。

Flutter／Dart 管理界面、会话、字幕排序与稳定判定、词表及上下文；Kotlin 管理收音、生命周期、音频缓冲、VAD 与任务调度；C/C++ 复用 whisper.cpp／llama.cpp，仅实现必要 JNI 封装。Pigeon 定义类型化桥接；原始 PCM 留在原生层。首版不引入 Rust、不启动本地 HTTP 推理服务、不部署独立后端。

音频为单声道 PCM，识别统一 16 kHz；设备采样率不匹配时真实重采样。不能根据骁龙 NPU 推断自动加速；比较 CPU 2／4／8 线程，默认 4 线程、串行重任务为初始基线，再按端到端结果评估受限并行或 GPU。8 线程只作为高性能设备评测项，不预设其一定更快。

### 分段与提交初始参数

目标链路使用本地 Silero VAD；约 600 ms 无人声触发收尾。当前小米兼容路径因 Silero 首帧原生崩溃暂用 RMS 能量门：静音时收尾，连续讲话最多约 7 秒强制形成最终识别，强制分段之间不重复音频。该路径暂不对不断增长的同一句周期性生成临时结果，以免重复推理和前缀抖动阻止提交。以上为开发集调优起点，并非性能承诺。

用相邻识别一致前缀、完整词和分句边界判断提交点；通过时间范围和文本对齐去重，不能删除真实重复发言。只有稳定英文进入翻译；中文确认后固定。没有安全提交点则继续等待并记录延迟失败，不强行推断后半句。翻译 10 秒超时从进入队列算起，包含排队时间。

收音和分段独立运行；ASR 与翻译使用独立工作队列，翻译积压不能阻塞识别或造成音频缓冲丢段。模型加载／释放与推理通过读写锁协调。ML Kit 单次翻译截止时间 10 秒，Qwen 单次翻译截止时间 30 秒；后续已完成译文可在原位置直接显示，不等待较早的慢请求。暂停／结束 1 秒内停止新输入，最多收尾 3 秒；之后逻辑取消并拒绝过期结果。可中断引擎请求取消；不能立即中断的 SDK 调用待安全退出再释放资源，其耗时纳入稳定性验证。

### 模型准备与管理

App 与模型分离分发；首用展示大小、测速、当前来源、下载进度、切源、校验和就绪状态。开发评测版在首页提供识别模型选择并明确显示下载状态，模型管理页同步标记当前模型；选择持久化，每次会话只加载所选的一个识别模型，不因同时下载多个模型而自动切换。Whisper、Qwen 与 Silero 的版本清单预置魔搭国内源、HF Mirror、Hugging Face，并固定到已核验的仓库提交。下载前并行请求各源 64 KiB 范围并验证 Content-Range，按耗时选择；超时、限流和服务端错误时保留 `.part` 断点并切换下一源。完整文件大小与 SHA-256 一致后才存入应用私有目录并启用；仍支持手动导入已验证格式与版本。ML Kit 使用官方管理接口，不提供模型导入或自行镜像。

会话中固定版本；仅在暂停或结束后更新、删除或切换，待任务退出后安全释放。模型缺失时只禁用对应组合。中国大陆网络下载优先使用测速胜出的预置源，具体可达性仍须实测；ML Kit 的 Google SDK 下载链路无法由 App 改源，失败时推荐使用 Qwen 离线翻译。

### 外部文本翻译

支持 Chat Completions 兼容协议、非流式回复；配置 API 基础地址、模型名、可选 Key。发送 model、messages、stream:false，读取文本回复，不自动发送非标准厂商参数。Key 使用系统安全存储。默认 HTTPS；用户明确允许时可用局域网 HTTP。连接测试使用固定测试句，不读取会话字幕。

### 决策门槛

默认离线组合必须通过全部首发质量、延迟与稳定性门槛并在保留集复现。多个候选通过时依次比较关键错误、理解率、术语／名称质量、P95 延迟和功耗。未通过时延长本地验证，必要时提交替代模型修订；不以云端增强通过替代离线发布。

## 数据、异常恢复与成本边界

### 最小数据契约

Session：会话 ID、运行代次、开始／结束时间、模式、英语→简中、词表版本、当场信息、状态。Segment：会话 ID、运行代次、稳定句子 ID、序号、音频起止时间、修订号、原文、译文、临时／确认／失败状态、结果显示时间。

Adapter：接受音频或文本请求；返回部分／最终结果与标准化错误。所有返回携带会话 ID、运行代次、句子 ID 和修订号；客户端忽略旧会话、旧代次与过期修订。暂停恢复／模式切换隔离旧任务。提示词和引擎／模型版本记录在诊断中，便于复现。

### F06 · 故障恢复规则

| 故障                     | 系统行为                                                                                                 |
| ------------------------ | -------------------------------------------------------------------------------------------------------- |
| 网络断开                 | 离线模式不受影响。外部翻译失败保留英文并受 10 秒截止时间约束重试；不缓存待上传音频，不自动切换服务 |
| 服务 429／额度耗尽       | 短时限流按服务重试提示退避，受队列上限约束；明确额度耗尽则停止请求并提示，不自动切换付费服务             |
| 识别有结果、翻译失败     | 显示英文与失败标记，后续句继续；收音空闲且无翻译任务时自动重试一次，结束回看可单条或全部手动重试             |
| 麦克风不可用／被打断     | 立即暂停；说明原因；恢复后由用户继续，不在后台静默开启                                                   |
| 模型缺失／损坏／内存不足 | 该本地模式不可选；允许重新下载或主动切换已配置模式                                                       |
| 推理持续落后             | 显示“处理跟不上”；原生未处理音频仅保留最近 10 秒，过旧音频丢弃时标明遗漏区间；合并临时任务；可暂停后切换已通过验证的组合                                     |

### 数据保留与联网说明

P0 默认不落盘原始音频；内存环形缓冲在消费、结束或退出后释放。字幕仅留本次会话，离开回看页前提示未保存内容将清除。P1 可增加本地保存、单条／整场删除与用户主动导出。

诊断默认只包含时延、状态、错误码和资源统计，不含音频、字幕、密钥。测试录音需显式开启；云端处理受所选供应商条款约束，不承诺供应商零留存。离线模式不得调用识别／翻译云端接口。

### 成本控制

离线模式无外部推理计费。外部增强仅统计文本 token、请求和重试；已知单价时估算，否则显示用量与“费用未知”。单次软预算可配置，到限停止外部翻译并保留本地英文。客户端估算不能保证账单硬上限；实际额度能力由用户所用供应商决定，无自建服务端额度校验。

| 指标               | 目标                             | 测量方法                                                                   |

| CS 术语正确率      | 至少 90%                         | 对人工标注的语境术语计算正确译法出现数／总出现数                           |

| 中文字幕延迟       | P50 ≤ 3秒；P95 ≤ 6秒           | 可对齐短句末尾音频在手机被采集，到该句稳定中文首次显示                     |

| 连续运行           | 60分钟无崩溃／ANR／不可恢复停止  | 3 次完整运行；每 10 分钟统计延迟，不能持续累积                             |
| 字幕一致性         | 确认句重复、乱序为 0             | 含重连、重试、暂停恢复与模式切换的脚本化测试                               |

### 资源与网络测试条件

基准：手机正常室温、不充电、固定 50% 亮度、同一 Wi-Fi；记录系统版本、RAM、剩余空间、电池健康和音量。网络仿真增加 150 ms RTT、1% 丢包与 10 秒断连。所有延迟同时报告成功覆盖率，超时／丢句不得从结果中隐藏。

小米首版建议资源预算：联网模式 60 分钟耗电不高于 15 个百分点；本地模式候选不高于 20 个百分点、进程峰值内存以 1.5 GB 为初始优化目标，超过后单独报告并基于质量收益、功耗与稳定性评审。均属工程预算，须经实机确认；发生系统严重热状态必须提示并允许停止。

iPhone 12 在第二阶段独立设立资源基线与门槛，不要求与小米运行相同模型；同样遵守准确性和不编造原则。支持大字号、横屏、安全区域与读屏按钮标签。

## 测试集与验证计划

### 数据集构建

准备 30 段采访片段，每段 1～2 分钟，总计约 45 分钟。覆盖至少 10 位说话人；包括清晰英语、不同非母语口音、现场噪声、密集 CS 术语及选手／战队／地图名称。另加 5 分钟纯音乐、观众声与静音负例。

按说话人和采访场次分为开发集 20 段、保留测试集 10 段；避免同一回答切片跨集合。每段记录原始视频链接、时间码与来源；评测使用权需满足来源要求，原始赛事片段不随 App 分发。

每段同时保留直接音轨作为诊断基准，以及手机对电脑外放的重录版本作为产品验收输入。手机实录是最终依据，不能用干净音轨成绩代替。

| -------- | --------------------- | -------------------------------- |

### 标注与分析规则

- 英文参考稿由人工对照音频校验；预先标注核心命题、关键否定／数字、术语和可接受名称别名。听不清的原始内容单独标记，不强行造参考答案。
- WER 用于定位识别错误：忽略标点与大小写，保留数字、名称和否定词；另报名称及术语错误率。中文以含义为主，不要求逐字贴合单一参考译文。
- 原型阶段可由用户主评；发布前关键错误由第二位熟悉 CS 且能听懂英文的人复核。对分歧记录裁决，不把模型自评当作最终真值。
- 标准环境需满足“成功指标与非功能验收”一节的全部门槛；挑战组单独报告，不与基准混合稀释成绩。静音／纯音乐负例应为零虚构采访译文。

产出：逐段结果、时延分布、资源曲线、失败样例、词表开关 A/B 对照。先定位收音／识别／翻译哪个环节出错，再决定是否加大模型。

## P2 储备需求：斗鱼同机直播翻译

> 修订记录：根据用户反馈新增本需求。优先级 P2；状态为已纳入需求、暂缓验证与开发。不加入 M0 必做项，不影响现有 P0／P1 排期和首版发布。

### 已知结果与能力边界

用户反馈：小米 15 使用系统录屏时，斗鱼直播能够录到声音。当前仅确认系统录屏路径有声音；尚未验证普通第三方 App 的内部音频捕获、悬浮显示或后台稳定性，也未分别确认耳机与外放。

### 目标体验与功能范围

P2-DY-01 · 入口与授权：新增“翻译本机直播”入口，原模式标为“听外部设备”。功能未交付前不显示可启动入口。进入同机模式时再申请内部音频采集和悬浮窗授权。

P2-DY-02 · 声音与翻译：优先使用斗鱼内部音频，复用英语识别、CS 术语表、上下文翻译与字幕状态。无法捕获时明确提示不可用，不静默切换麦克风。

P2-DY-03 · 悬浮字幕：半透明字幕区域，支持拖动、字号／透明度调整、收起、暂停与结束。适配斗鱼横屏全屏，避免遮挡比分和主要控制按钮。

P2-DY-04 · 后台运行：用户主动启动后，切到斗鱼仍继续处理，保留运行通知。此模式对“切后台暂停”规则作专项扩展；锁屏、来电及采集被撤销时仍暂停并提示。
