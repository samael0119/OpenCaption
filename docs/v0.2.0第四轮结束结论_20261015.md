# 第4完整轮结论：独立流式ASR架构筛选

2026-10-15。本轮（架构周期第1轮）已完成，按用户“继续一轮然后暂停”的最新指令停止。定时任务 opencaption 已实际设为 PAUSED 并读回核验；未启动第5轮。不是因额度耗尽停止。

## 结论

独立流式ASR在已知普通声材料上有明显局部收益，但低幅语音覆盖严重下降，尚不适合替换当前产品识别路径。FP32编码器没有修复这一缺陷。本轮不集成两候选，不宣称v0.2.0完成；已实现的队列、词库、自动辅助、UI与前轮协议/场景修复保留。

基线为已保存E2B原输出，明确作为缓存；两候选各实际运行41次，原始音频与参考未改变。没有把缓存算新推理或独立确认。

普通声净修复6句，词错误净减少14/15（93.33%）；这是源文局部收益，不是中文准确率增长93%。耳语修复3例、损失3例，净修复0；耳语WER从24/18到17/18主要反映插入错误减少，没有增加严格正确命令数。低幅六句全部漏掉是决定性护栏失败，不能用普通声或音乐收益抵消。音乐四段来自同一曲目，不能当作四个独立来源的安全保证。

两ASR候选原文41/41完全相同。仅编码器由int8变FP32，decoder/joiner仍int8，故只能否定“此编码器精度切换即可修复低幅失效”的本次假设，不能断言所有量化均无影响。未新增增益、VAD拒绝、热词或第三个候选。
