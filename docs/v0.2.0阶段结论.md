# OpenCaption v0.2.0 阶段结论

截至2026-10-14 14:30（北京时间），按用户要求暂时终止迭代。

**结论：低延迟分段、词库治理、基础自动场景与字幕UI已有可审查的产品实现和开发候选；准确性及高级能力的关键收益尚未证实，整版未通过验收，不应称为完成的v0.2.0。没有达到预期的晨间整版交付。**

## 各方向判定

| 方向 | 已实现/已验证 | 结论及限制 |
| --- | --- | --- |
| 字幕延迟 | 因果Silero停顿优先、600ms停顿/5秒兜底，固定窗回退；短输入收尾、E2B前置零补齐、有界合并、年龄与明确缺口；实际本机核心/widget首份60分钟完整 | 分段与调度路线可行。原5秒固定等待已经改变；模型服务与队列仍有耗时。没有人工语义结束→真实屏幕稳定中文计时，不能说P50≤3秒/P95≤6秒达标 |
| 词库本身 | 实体/别名/跨图关系/阵容时效分离；529原始条目、5窄条件纠正、24条AI辅助适用/反例审核、坏包回退与重载；相关预算240字符/96代理token | 结构和安全条件改善有证据，独立赛事术语≥20%净收益未证明。听错/漏掉ID时，下游检索缺少可靠依据；更新当前阵容快照不能替代历史生效关系 |
| 自动与高级辅助 | 选择CS2库默认开启已有证据/近期命中辅助，不新增必填；累计、弃权、冲突/时效/切图清理与可选当前会话纠正；一跳候选API与12条Nuke关系已有诊断 | 旧Nuke10窗真实闭环地图8/10、双队0/10，只属开发材料。不能承诺自动认出NAVI对FaZe；一跳候选及短语义前文尚未接正常生成，独立正向收益未验收，完整高阶能力未完成 |
| 字幕UI | 平整字幕行、原文/译文层级、较醒目最新译文、简洁可展开详情、回看滚动、可达纠正/恢复；Impeccable本机浅深/390交互与320/真实1.5字号验证 | 本机视觉/交互有通过证据和截图，已落实简洁阅读方向。Android实际悬浮绘制/移动未测，按用户要求没有连接手机；不把截图或headless组件代理当屏幕延迟 |

768 context保留为当前基线。现有加大模型/上下文及ASR备选的有限诊断没有解决所有关键漏词，没有依据调整默认模型或盲目增加上下文。相关检索的独立收益仍需可靠、未调参的赛事中英/场景材料；目前公开材料审查没有补齐这个缺口。

## 通过与未通过

- 当前产品候选完整Dart129项、Kotlin39项、静态分析、APK/Web构建和V2签名核验通过，92产品源与候选对应。应用仍0.1.0+2，未提交发布/推送。
- 新真实时钟核心/widget长稳仅**1/3份完成**：3600.013s、1009实际模型/控制器/widget结果、0队列缺口、0invalid、无观察OOM或swap，cgroup峰值3.864GiB。解码P50约1.94s/P95约3.33s、排队P95约2.03s均不是屏幕延迟。旧三份仅模型资源实验不能替代剩余两份。
- 音乐零虚构目标**失败**：首份82个样本定位的非零钢琴+补零窗口中2次实际可见虚构，18混语音边界排除。四段同曲旧材料循环，不是82独立来源。没有无补零配对，不能归因于短输入补零；低VAD拒绝候选曾误拒14/18真实耳语，未上线、不继续调同一门槛。
- 关键短答no/six漏词仍未完全解决；E4B和单一ASR诊断没有提供全面替换主线的依据。部分新短答补零有局部收益，不等价于完整准确性达标。
- 独立CS2人工中英参考、术语正向净收益、转会/历史/切图质量及自动场景准确/覆盖仍不足。新6例FLEURS真人/人工平行参考27.24s仅准备及12请求配置冻结，**尚未推理**；原12例准备未完整，不把通用朗读当赛事验收。
